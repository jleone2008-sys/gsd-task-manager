Every exercise for the day is visible from the moment you land — tap any "lbs" or "reps" cell and the focus sheet slides up over the page with the big numbers + quick-adjust pills you liked from the original C. The sheet's header ("Barbell row · Set 2 of 4 ▾") is itself a tap target — opens a quick-pick list of every exercise in the session so you can jump anywhere without backing out. Three Today renderers, one tab. The Today subtab picks its layout off the day's day_type (or, for the Any-day bonus pill, the user's session-type pill toggle):
  • lift → the exercise-cards UI (already designed under "Today · Lift")
  • cardio → modality pills + duration / distance / avg HR / calories (State A above)
  • bonus + Bonus Lifting → empty lift UI with "+ Add exercise" so the user composes a one-off session (State B)
  • bonus + Activity Log → name + duration rows, multi-add for chained activities (State C)
  • rest → "Rest day — no logging" with a "Log a bonus instead?" link that jumps to the Any-day pill
Day picker visually differentiates the modality of each day in the active plan: cardio day names render in moss-green, lift days in default ink, rest days muted. The dashed-border "+" pill on the right is always the Any-day bonus slot regardless of plan shape.

Habit library integration (Strategy B from the prior thread) hooks into submit-time:
  • Lift / Bonus-Lifting submit → marks any linked lifting-library habit complete for the day
  • Cardio submit → marks any linked cardio-library habit complete
  • Bonus + Activity Log submit → marks any linked activity-library habit complete
The unique constraint on habit_completions(user_id, habit_id, completed_date) means re-submits or manual taps before/after the auto-mark are all idempotent — historical data is never overwritten.

"Submit + Get Feedback" — formulaic first, AI on top

The feedback panel that opens after Submit has two layers stacked vertically. The formulaic layer always runs and always shows identical output for identical inputs (so screenshots, history, and trust all stay consistent). The AI layer is a single short narrative that ties the formulaic facts together — purely qualitative; nothing it says contradicts a number above.
Layer What it produces
Formulaic — LiftTotal volume (lbs) vs last session of same day · per-exercise PRs (new top set) · sets that hit target vs missed · suggested next-week target weights (rule-based: hit target → +2.5/+5 lbs; missed → repeat; readiness ≤ 60 → deload 10 %) · days since last lifting the same muscle group
Formulaic — CardioPace = duration / distance · pace vs your last same-modality session · estimated calories = METs(activity) × bodyweight(kg) × hours · weekly cardio totals (sessions, minutes)
Formulaic — Activity LogTotal minutes across all activities today · running 7-day activity count · variety chip if > 2 distinct activity types this week
Recovery alignmentJoins today's readiness / HRV / sleep_score from oura_daily with the session feel rating. Calls out misalignment ("you rated this 'Great' on a 46 readiness — solid push despite low recovery" or the inverse).
AI insight (top layer)One paragraph max. Pattern observations across the last ~4 weeks of sessions that the formulas alone can't surface (e.g. "Set 4 of squats has dropped reps three weeks in a row — try shorter rest", "Notes mention shoulder twice this week"). Tagged with confidence (high/medium/low). Falls back gracefully to empty if Claude is unavailable; the formulaic layer is always visible.
Consistency guarantee: every number in the feedback panel is a pure function of session data + recent history. The same inputs produce the same output every time. AI is constrained to narrative observations only — it never overrides or contradicts a number, and the formulaic layer renders even if Claude fails.
